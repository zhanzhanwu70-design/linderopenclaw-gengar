## 13:10 — watchdog now reports gateway-restart approval tickets (rowlet's two lessons)

1. **WAL gotcha (confirmed by test):** `~/.openclaw/state/openclaw.sqlite` runs in WAL mode.
   A read-only connection sees only checkpointed data, so a freshly created
   `operator_approvals` row is **invisible** unless `openclaw.sqlite-wal` and `-shm` are
   copied next to the .sqlite file first. Copy all three into a temp dir, then open
   `file:<tmp>/db.sqlite?mode=ro`. Verified: the pending ticket
   `system-agent:e33efcf4-e17f-4be4-b467-d96dbe8ff2bf` (created 13:05:50, expires 13:15:50)
   only appears that way; copying just the .sqlite shows it as missing.

   gateway-restart approvals as their own line, so Linder sees the ~10-minute approval
   window instead of a bare "restart never happened":
   - `Gateway restart approval PENDING (id …) - Linder has a ~10 min approval window open now, expires 11-17 13:15`
   - `Gateway restart approval EXPIRED without a decision (id …, expired …) - a new approval must be created`
     (only the most recent expiry is shown, so the watchdog does not alert on every cycle forever)
   Still exits 0 always (2026-10-30 rule) and prints NO_REPLY when healthy.
   Implementation note: the inner helper script must NOT use `%` string formatting — it
   contains `strftime('%m-%d %H:%M')`, which silently breaks the format string. Pass the db
   path via argv and print errors to stderr instead of failing silently.
