## 08:50 — heartbeat mitigation applied (isolated + light context)

The heartbeat streak (error ×3) was caused by the MiniMax Token Plan cap, and the main
session is huge (~627k/1.0m context, 587k tokens in), so **every heartbeat turn was
re-sending that whole context** — burning a large slice of the plan quota on each 30-minute
run. Fixed in `agents.entries.gengar.heartbeat`:
`{"every":"30m","target":"last","accountId":"gengar","directPolicy":"allow","timeoutSeconds":600,
